# skills

Agent Skills for Pi, Codex, Claude Code and Antigravity.

## Quick start

[`mise`][mise] runs every task. Set up a fresh checkout:

```console
$ mise trust
$ mise run setup
```

`mise tasks` lists everything else. See the [setup guide] for details.
